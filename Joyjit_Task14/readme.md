# JavaScript Basics Practice

## Overview

This repository contains beginner-friendly JavaScript programs designed to practice the fundamental concepts of programming. Each program focuses on solving a simple problem using loops, conditional statements, arithmetic operations, and built-in JavaScript functions.

These examples are helpful for students who have just started learning JavaScript and want to understand how basic programming logic works.

---

# Programs Included

## 1. Sum of Numbers from 1 to N

This program calculates the sum of all numbers from **1 to N** using a `for` loop.

**Example:**

If `N = 5`

```
1 + 2 + 3 + 4 + 5 = 15
```

---

## 2. Multiplication Table

This program prints the multiplication table of a given number from **0 to 10**.

**Example:**

For `N = 5`

```
5 × 0 = 0
5 × 1 = 5
5 × 2 = 10
...
5 × 10 = 50
```

## 3. Prime Number Check (Using If-Else)

This program checks whether a number is prime using conditional statements.

> **Note:** This method is only for basic learning purposes and is not suitable for checking every possible prime number.

---

## 4. Prime Number Check (Using For Loop)

This program checks whether a number is prime by counting its factors.

A prime number has exactly **two factors**:

* 1
* The number itself

If the total number of factors is **2**, the number is prime; otherwise, it is not.

---

## 5. Print All Factors of a Number

This program prints every factor of a given number.

A factor is a number that divides another number completely without leaving a remainder.

**Example:**

For `N = 12`

```
1
2
3
4
6
12
```

---

## 6. Sum of Digits of a Number

This program calculates the sum of all digits of a number using a `while` loop.

**Example:**

For `23`

```
2 + 3 = 5
```

The program repeatedly:

* Finds the last digit using the modulus (`%`) operator.
* Adds it to the sum.
* Removes the last digit using `Math.floor()`.

---

## 7. Armstrong Number Check

This program checks whether a number is an Armstrong Number.

An Armstrong Number is a number that is equal to the sum of the cubes of its digits.

**Example:**

```
153

1³ + 5³ + 3³
= 1 + 125 + 27
= 153
```

Since the calculated sum is equal to the original number, **153 is an Armstrong Number**.

## How to Run the Program

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code** (or any code editor).
3. Open the `index.html` file in your web browser.
4. Press **F12** or **Ctrl + Shift + I** to open the **Developer Tools**.
5. Go to the **Console** tab to view the program output.

> **Note:** All outputs are displayed in the browser's Developer Console using `console.log()`.

# Compound Interest Calculator

## Description
This project calculates the final amount and compound interest using the compound interest formula with static values in JavaScript.

## Formula
A = P * (1 + r / n) ^ (n * t)

Where:
- P = Principal Amount
- r = Annual Interest Rate
- n = Number of times interest is compounded per year
- t = Time (in years)
- A = Final Amount

Compound Interest = A - P

## Technologies Used
- JavaScript

   Index.html file and inspect the console section of this page to see the output.
